# eatee-site

Удалённый конфиг iOS-приложения Eatee (failover-конфигурация адресов).
Раздаётся через GitHub Pages: `https://eatee.flex-studio.tech/app-config.json`.

## Зачем

Адрес API в iOS-приложении не захардкожен: при старте приложение запрашивает этот файл
и берёт адреса из него. Это позволяет переключить все установленные копии приложения
на другой адрес **без нового релиза** — выпуск обновления через App Review занимает от 1 до 3 дней,
а пользователи обновляются ещё дольше.

Сценарии, на которые рассчитан конфиг:
- недоступность прод-сервера или домена (сбой хостинга, проблемы с DNS, истёкший домен/сертификат);
- переезд бэкенда на другой сервер или адрес;
- переезд страницы политики конфиденциальности.

## Почему отдельный хостинг

Резервный механизм не должен зависеть от того, что он страхует. Если положить конфиг
на прод-сервер или на домен eatee.ru, то при их недоступности конфиг станет недоступен
вместе с ними. GitHub Pages — независимая инфраструктура: бесплатно, с HTTPS и CDN,
изменение публикуется обычным коммитом.

## Формат

```json
{
  "api_base_url": "https://eatee.ru",
  "privacy_url": "https://eatee.ru/privacy"
}
```

| Поле | Назначение | Если поля нет |
|---|---|---|
| `api_base_url` | базовый адрес бэкенда для всех запросов приложения | `https://eatee.ru` |
| `privacy_url` | ссылка «Политика конфиденциальности» на экране регистрации | `https://eatee.ru/privacy` |

Текущее значение указывает на основной прод — `eatee.ru`. Конфиг меняется только при
инциденте или плановом переезде.

## Как работает в приложении

Код: `eatee/DataProvider/RemoteAppConfig.swift` (репозиторий фронтенда).

1. При запуске приложение в фоне скачивает `app-config.json` (таймаут 10 с).
2. Адреса сохраняются в `UserDefaults` и применяются со следующего же запроса.
3. Если конфиг недоступен или некорректен — используется последний сохранённый адрес,
   при первом запуске — значения по умолчанию (`eatee.ru`). Работа приложения от
   доступности конфига не зависит.

**Безопасность.** Принимаются только `https`-адреса на доверенных доменах
(`eatee.ru`, `flex-studio.tech` и их поддомены). Подмена файла не позволит увести запросы
пользователей и их токены на сторонний хост. Новый домен добавляется в список доверенных
только релизом приложения.

## Как поменять адрес

1. Отредактировать `app-config.json`, закоммитить и запушить в `main`.
2. GitHub Pages публикует изменение в течение 1–2 минут (кэш CDN — до 10 минут).
3. Пользователи получают новый адрес при следующем запуске приложения.

Проверка: `curl https://eatee.flex-studio.tech/app-config.json`

## Файлы

- `app-config.json` — конфиг.
- `CNAME` — домен GitHub Pages (`eatee.flex-studio.tech`, CNAME → `andrewflex.github.io`).
- `.nojekyll` — отключает обработку Jekyll, файлы раздаются как есть.
