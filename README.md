# eatee-site

Статика Eatee на GitHub Pages: `https://eatee.flex-studio.tech`.

- `app-config.json` — удалённый конфиг iOS-приложения (`RemoteAppConfig`):
  `api_base_url` — адрес API, `privacy_url` — политика конфиденциальности.
  Принимаются только https-адреса на `eatee.ru` / `flex-studio.tech`.
  Изменение применяется у пользователей при следующем запуске приложения.
